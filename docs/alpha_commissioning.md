# Alpha real-data commissioning

The commissioning path proves that a reviewed native strategy can consume admitted
market data and produce complete Bulletproof evidence before long qualification jobs
are scheduled. It is deliberately not a shortcut to scientific admission.

A commissioning assignment must:

- bind an independently reviewed, qualified strategy and the same source commit;
- use a positive window of no more than 31 days wholly inside the reviewed window;
- exhaust no more than eight preregistered variants through the classic engine;
- retain truth reports, selection-bias evidence, run bundles, trade logs, decision
  traces, representation contracts, memory receipts and a publication envelope;
- emit `execution_class: commissioning` and `qualification_authority: false`.

Commissioning results may reveal runtime, schema, transformation, logging or handoff
defects. Their performance metrics cannot satisfy out-of-sample admission, shadow,
promotion, risk or capital gates. The full reviewed window must subsequently run as
`execution_class: qualification` without changing the hypothesis, grid or code.
