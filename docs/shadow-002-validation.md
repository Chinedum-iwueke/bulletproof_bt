# SHADOW-002 validation

Bulletproof owns prospective health calculation. The producer binds a sealed SHADOW-001
journal, point-in-time observations, policy, candidate, dataset and source commit into
an immutable no-authority receipt. Future evidence is excluded. Missing, stale, outage,
drift, cost and drawdown evidence fails closed. Repeated breaches propose demotion;
healthy recovery still requires independent reactivation review.

The deterministic pilot exercises healthy, deterioration, stale and false-recovery
paths. It does not represent a live venue feed, authorize capital, place orders,
promote, demote or reactivate a candidate.
